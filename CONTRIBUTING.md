# Contributing
1. Open or select a GitHub issue.
2. Create a focused branch from `main`, e.g. `feat/request-fingerprint`.
3. Implement a small change and add tests.
4. Run `mvn test`.
5. Commit with a clear message, e.g. `feat: validate idempotency request payload`.
6. Open a PR describing the problem, solution, tests and trade-offs.

Use JDK 17+ and Maven 3.9+. Do not commit secrets or production data. Document limitations and avoid claiming guarantees the implementation does not provide.
